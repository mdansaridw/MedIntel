# Bundled fonts

The application currently bundles font files supplied from the local system font directory:

- `CormorantGaramond-VariableFont_wght.ttf`
- `StyreneB-Medium-Trial-BF63f6cc85760c2.otf`
- `InterVariable.ttf`

The Styrene B file is explicitly a Trial font. Confirm that its license permits redistribution and deployment before publishing the application. Replace it with a licensed production file if necessary.
